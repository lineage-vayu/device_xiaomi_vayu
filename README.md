# 📱 LineageOS device tree of Poco X3 pro

This repo contains the device tree for the **POCO X3 Pro** (codename: `vayu` / `bhima`) This tree includes all necessary device specific configurations to build for Snapdragon 860-powered POCO X3 Pro.
